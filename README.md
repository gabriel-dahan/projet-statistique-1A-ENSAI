# Projet Statistique

__Thème du projet__ : "Technologie et performances éducatives".

Ce projet est constitué de plusieurs parties ayant été créées tout au long de son développement : 

1. Une note exploratoire nous ayant servi à faire une première étude du sujet, et un choix de variables adaptées à son déroulement (branche `1_note_exploratoire`);
2. Une note d'étape (branche `2_note_d_etape`);
3. Un rendu V0 (branche `3_`);
4. Un rendu final (repo courant, synchronisé avec `3_`).

## Installation

Si vous souhaitez modifier et faire un nouveau rendu du projet,

 - Rendez-vous dans un environnement Quarto avec par exemple [RStudio](https://cran.rstudio.com/index.html).
 - Clonez ce repo, puis lancez le rendu Quarto ("Render" sur RStudio).
