# Projet Statistique

__Thème du projet__ : "Technologie et performances éducatives".

Ce projet est constitué de plusieurs parties ayant été créées tout au long de son développement : 

1. Une [note exploratoire](https://github.com/gabriel-dahan/projet-statistique-1A-ENSAI/tree/1_note_exploratoire) nous ayant servi à faire une première étude du sujet, et un choix de variables adaptées à son déroulement;
2. Une note d'étape (pour 03/03/2026).
3. Un rendu V0 (non commencé).
4. Un rendu final (repo courant).

## Installation

Si vous souhaitez modifier et faire un nouveau rendu du projet,

 - Rendez-vous dans un environnement Quarto avec par exemple [RStudio](https://cran.rstudio.com/index.html).
 - Clonez ce repo, et uploadez-y le fichier `stu_qqq.rds` disponible [ici](https://pages.gabrieldahan.me/files/ensai/stu_qqq.rds).
 - Vous pouvez alors lancer un rendu quarto du fichier qui vous intéresse directement en cliquant sur le bouton "Rendu".
